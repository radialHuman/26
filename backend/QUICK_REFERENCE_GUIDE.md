## 💡 TOP 10 MENTAL MODELS

1. **Layers of Abstraction**
   - Each layer does ONE job (TCP, HTTP, Application)
   - Problems usually at layer boundaries

2. **Stateless vs Stateful**
   - HTTP is stateless, sessions make it stateful
   - Design for stateless when possible

3. **Request/Response Cycle**
   - Everything follows: Request → Process → Response
   - Applies to HTTP, RPC, messaging

4. **Async vs Sync**
   - Single thread can handle millions of concurrent connections
   - Avoid blocking operations (database, network)

5. **Caching Everywhere**
   - DNS caching, HTTP caching, database caching, application caching
   - Caching is THE lever for performance

6. **Timeouts Matter**
   - Network timeouts, connection timeouts, request timeouts
   - Missing timeouts = cascading failures

7. **Error Handling**
   - Fail gracefully with proper status codes
   - Log errors for debugging
   - Retry with exponential backoff

8. **Idempotency**
   - Same request multiple times = same result
   - Critical for reliability

9. **Transactions**
   - All or nothing database operations
   - Prevents inconsistent state

10. **Scalability Trade-offs**
    - Can't have perfect consistency, availability, partition tolerance
    - Choose 2 of 3 (CAP theorem)

## 📞 GETTING UNSTUCK

**When you don't understand something:**
1. Read the official documentation first
2. Search for visual explanations (YouTube, diagrams)
3. Write code to test your understanding
4. Ask in communities (Reddit, Discord, Stack Overflow)
5. Look at open-source implementations
6. Teach someone else (forces clarity)

**When stuck on a problem:**
1. Take a break (20 minutes minimum)
2. Restate the problem clearly
3. Check if it's a known issue (Google + StackOverflow)
4. Use debugging tools (print, debugger, logging)
5. Simplify to minimal reproducible example
6. Ask for help with specific details
