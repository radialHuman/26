# RabbitMQ
Message broker implementing AMQP. Great for task queues.
✓ Flexible routing, mature ✗ Lower throughput than Kafka
Use for: Task queues, job processing, microservices
Features: Priority queues, dead letter queues, TTL
Python: `pika`, Go: `github.com/rabbitmq/amqp091-go`
Docs: https://www.rabbitmq.com/
