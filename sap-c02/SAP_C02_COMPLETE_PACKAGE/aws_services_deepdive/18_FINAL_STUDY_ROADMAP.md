## 🎓 Study Techniques That Work

### Active Recall
```
Don't: Read documentation passively
Do: Read then close doc, write summary from memory

Example:
Read EC2 pricing section → Close doc → Write from memory:
"Reserved Instances: 1-3 year commitment, 72% savings, Standard can't change, Convertible can change family..."

If stuck: Reread, repeat until can write without looking
```

### Spaced Repetition
```
Day 1: Learn VPC
Day 2: Review VPC (quick)
Day 4: Review VPC again
Day 8: Review VPC
Day 16: Review VPC

Spacing increases retention 10x vs cramming
```

### Teach Someone Else
```
Best learning: Explain to others

Create study group or:
- Explain concepts to rubber duck
- Write blog posts about topics
- Create your own flashcards
- Answer questions on Reddit/forums
```

### Practice Under Exam Conditions
```
Mock exams:
- 75 questions
- 180 minutes (use timer!)
- No breaks
- No looking up answers
- Flag difficult, review at end

Simulate real exam pressure
```
